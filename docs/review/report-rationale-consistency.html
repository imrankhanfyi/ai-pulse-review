How this report was produced

Each judge provides a text rationale alongside their scores. This report checks whether those rationales actually support the scores given. An independent model (Gemini 2.5 Flash, not on the judge panel) reads each rationale and infers what scores it would justify based on the rubric — without seeing the original model response. If the inferred scores match the given scores, the pair is consistent.

150 rationale-score pairs were sampled from 2,504 total (stratified across judges, scenarios, and score levels).

Verdict definitions

Consistent — the meta-judge's inferred scores both match the judge's given scores. The rationale supports the numbers.

Inconsistent — the meta-judge infers a different score on at least one dimension. The gap size indicates severity.

Indeterminate — the rationale is too vague for the meta-judge to infer a score. This is itself a signal — vague rationales are less trustworthy even if the score happens to be correct.
